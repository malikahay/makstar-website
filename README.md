# Makstar — сайт макарон

Next.js 16 (App Router) + Tailwind CSS 4 + Framer Motion + Lenis.

Бэкенд — Go (chi + GORM + golang-migrate) и PostgreSQL в папке `backend/`.

```bash
cp .env.example .env      # задайте JWT_SECRET и ADMIN_PASSWORD
docker compose up -d      # Postgres :5433 + Go API :8080 (миграции применяются при старте)
npm install
npm run dev               # http://localhost:3000 — проксирует /api и /admin на Go
```

Без Docker: `cd backend && DATABASE_URL=postgres://… JWT_SECRET=… ADMIN_EMAIL=… ADMIN_PASSWORD=… go run ./cmd/server`.

Аккаунт из `ADMIN_EMAIL` при старте API создаётся (или получает роль админа). Пароль из `ADMIN_PASSWORD` задаётся только при создании — у существующего аккаунта он не меняется. Остальных админов назначают в админке → «Пользователи».

### Уведомления в Telegram
Новые заказы и сообщения из формы контактов приходят в Telegram-группу:
1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен → `TELEGRAM_BOT_TOKEN`.
2. Добавьте бота в группу и напишите в ней любое сообщение.
3. Откройте `https://api.telegram.org/bot<токен>/getUpdates` и возьмите `chat.id` группы (отрицательное число) → `TELEGRAM_CHAT_ID`.
4. `SITE_URL` (например, `https://makstar.uz`) — для ссылок «Открыть в админке».

Пока переменные пустые, уведомления выключены — заказы и сообщения всё равно сохраняются и видны в админке.

### Перед публикацией
- Вход, регистрация, заказы и форма контактов ограничены по числу запросов с одного IP. IP берётся из `X-Forwarded-For`, поэтому перед сайтом должен стоять обратный прокси (Caddy, nginx), который **перезаписывает** этот заголовок реальным IP клиента. Go API не должен быть доступен из интернета напрямую.
- `COOKIE_SECURE=true` (сайт только по HTTPS).
- Реквизиты компании для оферты и политики — `SITE.company` в `src/lib/site.ts`; тексты документов — `src/i18n/legal.ts`.
- Персональные данные граждан Узбекистана по закону должны храниться на серверах в Узбекистане — это учитывается при выборе хостинга.

## Страницы
| Маршрут | Что там |
|---|---|
| `/` | Главная: hero с параллаксом, манифест, горизонтальная линейка, 3 способа, цифры, рецепты, CTA |
| `/catalog` | Каталог с фильтрами (тип, способ готовки, сортировка) |
| `/catalog/[slug]` | Карточка товара: вес, количество, вкладки, кухонный таймер, рецепты |
| `/recipes` | Рецепты с фильтром и раскрывающейся карточкой (`?m=boil\|fry\|bake`) |
| `/about` | О нас: процесс производства, ценности |
| `/cart`, `/checkout` | Корзина (промокод `MAKSTAR10`) и оформление в 3 шага |
| `/delivery` | Доставка и оплата, калькулятор бесплатной доставки |
| `/contacts` | Контакты, форма, FAQ |
| `/register`, `/login`, `/account` | Регистрация, вход, личный кабинет с историей заказов |
| `/offer`, `/privacy` | Публичная оферта и политика конфиденциальности |
| `/admin` | Админка (Go + htmx): статистика, заказы и статусы, сообщения, товары и фото, пользователи и роли |

## Где что менять
- Товары и цены — в админке (`/admin/products`). `src/lib/products.ts` — типы и запасной каталог на случай, если API недоступен
- Схема БД — `backend/migrations/` (новые изменения — новым файлом `00000N_*.up.sql`)
- Цены заказа, промокод и доставка считаются на сервере — `backend/internal/store/queries.go`
- Телефон, email, соцсети и реквизиты — `src/lib/site.ts` (пустая ссылка на соцсеть скрывается)
- Рецепты — `src/lib/recipes.ts`
- Цвета и шрифты — `src/app/globals.css` (`@theme`)
- Переход между страницами — `src/components/TransitionProvider.tsx` (используйте `TLink` вместо `Link`)

Иллюстрации макарон и пачек — SVG/CSS (`Pasta.tsx`, `Pack.tsx`). Если у товара загружено фото в админке, оно показывается вместо нарисованной пачки.
Контакты, адрес, цифры и отзывы — заглушки, замените на реальные.
